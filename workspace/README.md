# USMA Class Timer

A minimal, distraction-free countdown timer for USMA class periods. Designed for cadets and instructors to track remaining time in classes without distractions.

## Features
- **Automatic Schedule Tracking**: Follows USMA's academic calendar and daily class periods (A1, B1, C2, etc.).
- **Visual Countdown**: Displays time remaining until the next class ends, with a red warning when time is low.
- **Fullscreen Mode**: Optimized for classroom display to avoid distractions.
- **Customizable**: Select which class periods to display via a simple prompt.
- **Dark/Light Mode**: Toggle between themes for visibility in any lighting condition.
- **Persistent Settings**: Remembers selected class hours using browser storage.

## Quick Start
1. Navigate to the USMA Class Timer web application.
2. Click the countdown timer to enter fullscreen mode.
3. Click the current time to toggle dark/light mode.
4. Click the class period identifier (e.g., "A1") to customize which periods are displayed.
